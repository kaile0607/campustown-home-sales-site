# College Town Home Sales Dashboard

## What this site is for

This website provides an interactive dashboard for exploring home sales across college towns in the United States. It allows users to compare median home prices across 18 cities near 11 university campuses.

The dashboard displays the total number of home sales, median sale prices, and a bar chart comparing housing prices across cities. Users can also filter by city to explore individual housing markets.

## Live site

https://kaile0607.github.io/campustown-home-sales-site/

## Data notes

The website uses the College-town Home Sales Dataset, version 1.0 (2026), containing 35,442 home sales.

Total home sales: Counts all completed transactions in the dataset.

Median sale price: The middle sale price among qualifying transactions.

City comparisons: Median sale prices are calculated separately for each city.

Data filtering: Sales below $10,000 are excluded from price statistics to avoid implausible values. These transactions are still included in the total sales count.
